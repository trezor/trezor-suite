## Suite Sync (desktop and web)

Reusable desktop and web parts of Suite Sync: UI components, settings and state.
The concrete Evolu setup and composition live in `@suite-app/suite-sync`.
The shared logic lives in `@suite-common/suite-sync`.

For what Suite Sync does, its terms, keys and authentication flow, see the [Suite Sync documentation](../../docs/features/suite-sync.md).
