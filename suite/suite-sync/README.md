## Suite Sync (desktop and web)

Reusable desktop and web parts of Suite Sync: UI components, settings, state and the desktop factory contract.
The concrete Evolu setup and composition live in `@suite-app/suite-sync`, selected by the web and desktop entry points.
The shared logic lives in `@suite-common/suite-sync`.

For what Suite Sync does, its terms, keys and authentication flow, see the [Suite Sync documentation](../../docs/features/suite-sync.md).
