## Skills

**All skills are mandatory reading** before making changes.

Apart from [top-level AGENTS.md](../../AGENTS.md), the following skills are mandatory for **Suite E2E Testing**:

- [Assertions Strategy](skills/assertions/SKILL.md) – Translation validation, custom matchers, display assertions
- [Fixtures](skills/fixtures/SKILL.md) – Playwright fixture architecture, dependency injection, test scope
- [Locators Strategy](skills/locators/SKILL.md) – TestID convention, parameterization, strict naming rules
- [Page Objects](skills/page-objects/SKILL.md) – Page object structure, composition, @step decorators, naming
- [Await & Retry Strategy](skills/retries/SKILL.md) – Playwright auto-waiting, custom polling, Redux waits, flakiness prevention
- [Test Tagging](skills/tagging/SKILL.md) – Device models, platforms, execution scope, project filtering
- [Agentic Test Creation](skills/agentic-test-creation/SKILL.md) – Mandatory discovery-first workflow for writing new tests from user stories
