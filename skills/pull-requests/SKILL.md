# Pull requests

Follow the mandatory [write rules](../github-write-actions/SKILL.md) for every PR description, comment and review.

## Create

Follow the [PR description template](../../.github/pull_request_template.md). Notes for QA follow [QA notes](../qa-notes/SKILL.md).

## Review

Use the GitHub CLI (`gh`) for all GitHub interactions during PR reviews.

Submit a review only as a comment, never as an approval or a change-request verdict, whether it finds no issues or blockers. State the outcome in the text.

Review the changes against the skills that apply to the changed code.
