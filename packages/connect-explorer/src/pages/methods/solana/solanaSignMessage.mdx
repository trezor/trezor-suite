## Solana: Sign message

Asks device to sign a Solana off-chain message ([OCMS v1](https://docs.anza.xyz/proposals/off-chain-message-signing#envelope)). User is asked to confirm the message on Trezor.

```javascript
const result = await TrezorConnect.solanaSignMessage(params);
```

### Params

<CommonParamsLink />

#### SolanaSignMessage

<ParamsTable schema={SolanaSignMessage} descriptions={paramDescriptions} />

### Example

```javascript
TrezorConnect.solanaSignMessage({
    path: "m/44'/501'/0'/0'",
    message: 'Hello, Trezor!',
});
```

With explicit signers (the signing key derived from `path` must be included):

```javascript
TrezorConnect.solanaSignMessage({
    path: "m/44'/501'/0'/0'",
    message: 'Hello, Trezor!',
    signers: [
        '14CCvQzQzHCVgZM3j9soPnXuJXh1RmCfwLVUcdfbZVBS', // signing key
        '7v91N7iZ9mNicL8WfG6cgSCKyRXydQjLh6UYBWwm6y1Q', // additional co-signer
    ],
});
```

### Result

[SolanaSignedMessage type](https://github.com/trezor/trezor-suite/blob/develop/packages/connect-common/src/types/api/solana/common.ts)

```javascript
{
    success: true,
    payload: {
        signature: string,   // hex-encoded Ed25519 signature over the OCMS v1 envelope
        signedData: string,  // hex-encoded serialized OCMS v1 envelope (optional)
    }
}
```

Error

```javascript
{
    success: false,
    error: {
        message: string // error message
    }
}
```
