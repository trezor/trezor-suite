## Get public key

Retrieves BIP32 extended public derived by given BIP32 path.
User is presented with a description of the requested key and asked to confirm the export.

```javascript
const result = await TrezorConnect.getPublicKey(params);
```

### Params

#### GetPublicKey

<ParamsTable schema={GetPublicKey} descriptions={paramDescriptions} />

#### Bundle(GetPublicKey)

<Param name="bundle" type="`Array` of Objects with above schema" />

### Example

Return public key of fifth bitcoin account:

```javascript
TrezorConnect.getPublicKey({
    path: "m/49'/0'/4'",
    coin: 'btc',
});
```

Return a bundle of public keys for multiple bitcoin accounts:

```javascript
TrezorConnect.getPublicKey({
    bundle: [
        { path: "m/49'/0'/0'" }, // account 1
        { path: "m/49'/0'/1'" }, // account 2
        { path: "m/49'/0'/2'" }, // account 3
    ],
});
```

### Result

[HDNodeResponse type](https://github.com/trezor/trezor-suite/blob/develop/packages/connect-common/src/types/api/account/getPublicKey.ts)

Result with only one public key

```javascript
{
    success: true,
    payload: {
        path: Array<number>,          // hardended path
        serializedPath: string,       // serialized path
        xpub: string,                 // xpub in legacy format
        xpubSegwit?: string,          // optional for segwit accounts: xpub in segwit format (SLIP-132)
        chainCode: string,            // BIP-32 serialization format
        childNum: number,             // BIP-32 serialization format
        publicKey: string,            // BIP-32 serialization format
        fingerprint: number,          // BIP-32 serialization format: fingerprint of the parent node, not the master key
        rootFingerprint?: number,     // master (root) key fingerprint as uint32, since Connect 10.0.0. See below
        depth: number,                // BIP-32 serialization format
        descriptor?: string,          // BIP-380 descriptor. Not available on firmware older than 2.7.0 (Trezor Model One: 1.14.0)
        displayablePublicKey: string, // exactly what the device shows: the xpub in the SLIP-132 form matching the scriptType (e.g. ypub/zpub for SegWit), for Taproot the `descriptor` when present
    }
}
```

> **`displayablePublicKey` is what the device shows.** It is byte-identical to
> the string the device renders when `showOnTrezor: true`, so show it next to an
> on-device verification. For Taproot that is firmware's descriptor with
> `h`-notation and checksum, e.g. `tr([fp/86h/0h/0h]xpub…/<0;1>/*)#checksum`
> (firmware older than 2.7.0, or 1.14.0 on Trezor Model One, shows the bare
> `xpub`). To query a backend, use `xpubSegwit ?? xpub`: for Taproot,
> `xpubSegwit` is the same descriptor with `'`-notation and without the checksum.

> **`fingerprint` vs. `rootFingerprint`.** `fingerprint` is the parent
> fingerprint stored in the BIP-32 serialization of the returned node. It is
> the same for every account under one parent (e.g. all `m/84'/0'/x'`
> accounts) and equals the master fingerprint only for depth-1 nodes. For the
> master fingerprint, e.g. the key origin `[xxxxxxxx/84'/0'/0']` of a
> descriptor or a PSBT `BIP32_DERIVATION` entry, use `rootFingerprint`,
> available since Connect 10.0.0. Both are `uint32` numbers; the usual
> 8-character hex form is `rootFingerprint.toString(16).padStart(8, '0')`,
> which matches the key origin in `descriptor`.

[Read more about BIP32 serialization format](https://github.com/bitcoin/bips/blob/master/bip-0032.mediawiki#Serialization_format)

Result with bundle of public keys

```javascript
{
    success: true,
    payload: [
        { path, serializedPath, xpub, xpubSegwit?, chainCode, childNum, publicKey, fingerprint, rootFingerprint?, depth, descriptor, displayablePublicKey }, // account 1
        { path, serializedPath, xpub, xpubSegwit?, chainCode, childNum, publicKey, fingerprint, rootFingerprint?, depth, descriptor, displayablePublicKey }, // account 2
        { path, serializedPath, xpub, xpubSegwit?, chainCode, childNum, publicKey, fingerprint, rootFingerprint?, depth, descriptor, displayablePublicKey }  // account 3
    ]
}
```

Error

```javascript
{
    success: false,
    error: {
        message: string // error message
    }
}
```
