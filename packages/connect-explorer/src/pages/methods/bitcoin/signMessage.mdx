## Sign message

Asks device to sign a message using the private key derived by given BIP32 path.

You can provide either a `path` (BIP32 derivation path) or an `address`. When using `address`, the Suite connect-popup resolves it to the corresponding derivation path from discovered accounts.

```javascript
const result = await TrezorConnect.signMessage(params);
```

#### SignMessage

### Example

```javascript
// Using path
TrezorConnect.signMessage({
    path: "m/44'/0'/0'",
    message: 'example message',
});

// Using address (requires Suite as connect-popup host)
TrezorConnect.signMessage({
    address: 'bc1qexampleaddress',
    coin: 'btc',
    message: 'example message',
});
```

### Result

[MessageSignature type](https://github.com/trezor/trezor-suite/blob/develop/packages/protobuf/src/messages.ts)

```javascript
{
    success: true,
    payload: {
        address: string,   // signer address
        signature: string, // signature in base64 format
    }
}
```

Error

```javascript
{
    success: false,
    error: {
        message: string // error message
    }
}
```
