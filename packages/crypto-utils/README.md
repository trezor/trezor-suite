# @trezor/crypto-utils

[![NPM](https://img.shields.io/npm/v/@trezor/crypto-utils.svg)](https://www.npmjs.org/package/@trezor/crypto-utils)

Collection of cryptocurrency utils. This is place for "packages" that are used in both Connect and Suite,
but they are too small to have its own package.

Creating a package that is used by Conenct is a bit more work. But if any sub-package here is bigger,
it shall get its own proper package.
