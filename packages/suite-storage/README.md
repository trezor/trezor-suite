# @trezor/suite-storage

This package contains an abstract database definition for Suite. Both [@suite/desktop-app](../suite-desktop) and [@suite/web-app](../suite-web) use [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API) for storage. IndexedDB is accessed via [idb](https://github.com/jakearchibald/idb) package.
