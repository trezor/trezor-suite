# @trezor/suite-storage

This package contains an abstract database definition for Suite. Both [@suite-app/desktop-app](../../suite-app/desktop-app) and [@suite-app/web-app](../../suite-app/web-app) use [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API) for storage. IndexedDB is accessed via [idb](https://github.com/jakearchibald/idb) package.
