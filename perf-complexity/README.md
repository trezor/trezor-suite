## Before filing, read this

**No number in these documents is a measurement.** The audit verified locations, code, and complexity
classes by reading — twice, by independent agents — but nothing was benchmarked. Where a document cites a
figure (322 ms, 167 ms → 1.7 ms, 227 ms) it is explicitly attributed to #31123, #31126 or #31122, which did
measure their own defects. Do not carry those numbers into an issue as if they described this code.

**The `After` hunks have not been compiled.** They are written against the surrounding types by reading,
not by running `tsc`. Treat them as a reviewed proposal, not a patch.

**Status column** below: `full` means the document was written by reading the source file end to end, with a
bespoke `After` hunk. `draft` means it was assembled from the verified audit findings — the `Before` block is
a verbatim window from the file, but the `After` reuses the fix text from the audit and deserves a closer
look before the issue goes up.
