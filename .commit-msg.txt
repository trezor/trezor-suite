fix(build): unblock CI for tsdown migration

- Restore tsconfig.base.json extends in suite-desktop-core/scripts
  (was extending the deleted root tsconfig.lib.json).
- Allow `export default` in tsdown.config.ts files (the tsdown CLI
  requires it; ESLint otherwise blocks via import/no-default-export).
- Add `tsc --build tsconfig.json` pre-step to the four packages with
  inlineDevDepTypes (connect-common, connect-web, connect-webextension,
  connect-mobile). This generates libDev/ for upstream workspace deps
  via tsc project references, which inline-devdep-types.mjs needs to
  parse declarations. Required because pack-packages.ts in CI invokes
  build:lib via `yarn workspace …` directly, bypassing the nx
  ^build:lib dependency that lib/ would otherwise satisfy.
