### 🚀 New features

- Users can long-press the QR code or address to copy, share, or save it to Photos — on iOS via a native menu, on Android by copying the address directly
- Suite shows a post-trade info card and a feedback prompt
- Suite resolves ENS names for Send transactions on EVM networks
- Indonesian language now supported on mobile
- MEV protection is now enabled for Robinhood transactions
- Support for root Solana derivation path (m/44'/501'), making it easier to migrate accounts from other wallets

### 🎨 Improvements

- Receive screen shows full address immediately
- Crypto amounts shown with consistent decimal formatting
- Sell flow now features a preview step plus other improvements
- Trade provider picker has a refreshed look
- Indonesian and Simplified Chinese added as official languages
- Earn dashboard has a redesigned overview, plus refined bonus rewards summary and claim flow
- Feedback form added to the end of the staking flow
- Refreshed Cardano (ADA) view-only staking UI
- Improved XPUB / QR code behavior

### 🔧 Bug fixes

- Cancel action for pending EVM transactions
- Crypto and fiat decimal display precision consistency
- Switching accounts during Buy flow no longer crashes the app if a background asset-info refresh fails
- Re-opening the slippage menu on a DEX swap and changing it again now correctly updates the swap offer amount each time
- Solana bug where wallets with many accounts (or multiple open tabs) could flood the backend
- Fixed Stellar token activation failing
- Yield flow updated on Android and for Trezor Model One
