### 🚀 New features

- Passphrases can now be up to 128 characters long
- ADA and Cardano native tokens full Send flow added
- You can now swap Bitcoin on mobile, via both DEX and CEX providers
- Arc EVM network now supported
- Sign & Verify now possible on mobile

### 🎨 Improvements

- Trade form retains previously-entered values when navigating the app
- Tron account activation fee is now included in the network fee in Trade and Send
- Stellar Soroban (SEP-41) tokens have improved support; users can Send & Receive them and use them with DeFi apps
- Updated view-only Tron staking UI

### 🔧 Bug fixes

- Revoke and Approval flows fixed for USDT swaps on DEX
- Trade history CSV export includes Spend transactions for CEX swaps
- Stellar USDC appears in the (inactive) tokens list
- Earn screen rendering & performance fixes
